# Security

## Supported versions

EdgePilot is an early preview. Security fixes target the current main branch and the latest preview; no long-term support policy is promised.

## Reporting a vulnerability

Do not post credentials, exploit details or private diagnostics in public issues.

If GitHub shows **Security → Report a vulnerability**, use private vulnerability reporting. If that option is unavailable, open an issue containing only a request for a private reporting channel, without vulnerability details, and wait for the maintainer to arrange one. No response-time commitment is currently offered.

## Scope and data

EdgePilot samples local system metrics and stores local preferences. It has no cloud monitoring backend or telemetry uploader. Optional startup integration and installation apply to the current user. Releases are currently unsigned.

Review logs and screenshots before sharing: hostnames, mount points and disk labels can contain personal information.
