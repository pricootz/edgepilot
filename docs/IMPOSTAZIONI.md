# Settings documentation

The current English guide is [Settings](SETTINGS.md).

La base v0.3 aggiunge la scelta del monitor nella pagina Pannello: Automatico segue il monitor principale disponibile, mentre una scelta esplicita viene ricordata anche durante una disconnessione o lo spegnimento temporaneo. EdgePilot usa nel frattempo un monitor disponibile e torna su quello scelto quando ricompare. Su Windows mostra il modello EDID quando è rilevabile, altrimenti usa etichette numerate come `Monitor 1` e `Monitor 2`.
