# Settings documentation

The current English guide is [Settings](SETTINGS.md).

La base v0.3 aggiunge la scelta del monitor nella pagina Pannello: Automatico segue il monitor principale disponibile, mentre una scelta esplicita viene ricordata durante una disconnessione. EdgePilot usa nel frattempo un monitor disponibile e torna su quello scelto quando ricompare. Se il pulsante fisico lascia invece il monitor ancora dichiarato attivo da Windows, dalla tray apri **Sposta EdgePilot su** e scegli direttamente il monitor visibile; resta disponibile anche **Sposta EdgePilot su questo monitor**. Il comando forza e verifica lo spostamento e mostra brevemente la notch. In alternativa usa **Usa il monitor che contiene Impostazioni**. Su Windows viene mostrato prima il modello EDID, poi il codice hardware (per esempio `AOC3279`) e infine, solo se entrambi mancano, `Monitor 1`, `Monitor 2`.
