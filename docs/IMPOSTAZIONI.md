# Settings documentation

The current English guide is [Settings](SETTINGS.md).

La base v0.3 aggiunge la scelta del monitor nella pagina Pannello: Automatico segue il monitor principale disponibile, mentre una scelta esplicita viene ricordata durante una disconnessione. EdgePilot usa nel frattempo un monitor disponibile e torna su quello scelto quando ricompare. Se il pulsante fisico lascia invece il monitor ancora dichiarato attivo da Windows, usa **Sposta EdgePilot su questo monitor** dalla tray oppure **Usa il monitor che contiene Impostazioni** per un recupero immediato. Su Windows mostra il modello EDID quando è rilevabile, altrimenti usa etichette numerate come `Monitor 1` e `Monitor 2`.
