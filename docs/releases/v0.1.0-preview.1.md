# EdgePilot v0.1.0-preview.1

First preview of a compact screen-edge system monitor for Windows and Linux.

## Included

- CPU, RAM, disk capacity, network throughput and system details.
- Four-edge notch with spring motion, tooltips, hover/fold and pin.
- Persistent settings, disk selection, tray and optional start at login.
- Per-user installation and self-contained x64 packages.

The application UI is **Italian**. Project documentation is **English**.

## Downloads

- Windows x64: EdgePilot-win-x64.zip
- Linux x64: EdgePilot-linux-x64.tar.gz
- Each archive has a matching SHA-256 file.

Extract the complete archive and follow its README.md. The .NET runtime is included. A graphical Linux desktop is required; GNOME may need AppIndicator support.

## Preview status

Packages are unsigned; updates are manual. Linux transparency, tray and system theme support depend on the desktop. Settings use Avalonia controls rather than native GTK/Yaru widgets. Broader DPI, monitor and login testing is still needed.

Network interface selection, GPU, temperatures and fan sensors are not included.

Report issues with version, OS, desktop session and reproduction steps. Review screenshots for personal information before uploading.
